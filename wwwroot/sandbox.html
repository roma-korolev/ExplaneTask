Что делать на этой странице
  1. Нажмите «Случайная задача» (или выберите тип задачи).
  2. Решите задачу, введите ответ числом, нажмите «Проверить». Засчитывается первая попытка.
  3. После ответа вы увидите решение. Нажмите «Следующая задача».
  4. Можно загрузить свою картинку и получить по ней две задачи (ниже).

Решение:

Своя картинка

1) Выберите файл (PNG, GIF, JPEG, BMP, WebP). 2) Нажмите одну из двух кнопок — задача появится в рамке выше. Файл никуда не сохраняется: сервер лишь считает цвета. Размер — до 4 млн пикселей.

Допущения: без сжатия и служебных данных; 1 байт = 8 бит; 1 КиБ = 1024 байта. Задачи — авторские, по типовым заданиям школьного курса информатики (кодирование графической информации).
