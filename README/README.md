##Запуск:
  1. Запустить Program.cs или run.bat для windows. 
  2. Запустить wwwroot/index.html.


#Инструменты:
  1. C# - "серверная" часть.
  2. .NET 8 SDK - для запуска сервера.
  3. ASP.NET Core Minimal API - маршруты api в "серверной" части.
  4. Kestrel - локальный сервер.
  5. System.Text.JSON - для обмена данными между сервером и приложением.
  6. HTML5, CSS, JS - фронтенд.

#Архитектура:
  В целом архитектура отображена на архитектура.png

  Для бэкенда:
  Модуль	Назначение
  Обработчик кнопок	выдаёт шаги разборов, данные для сетки пикселей и палитры, обрабатывает «Следующий шаг» и «Сначала»
  Чекер	сравнивает ответ с правильным и объясняет типичную ошибку
  Генератор задач	создаёт случайные задачи двух типов (глубина цвета, объём)
  Обработчик картинок	считает цвета загруженной картинки и составляет две задачи
  Статистика	хранит процент верных ответов за всё время и за последние 10

  Для фронтенда каждый модуль выполняет функцию, отображённую на схеме.

#Обоснование технологий:
  C# был использован, т.к. в данный момент мы проходим его на занятиях.
  .NET 8 SDK был использован т.к. его легче всего применить для данной задачи.
  ASP.NET был использован, т.к. он позволяет довольно удобно написать api на C# и мне было бы интересно с ним поработать.
  HTML, CSS, JS были выбраны т.к. они являются самыми популярными инструментами для фронтенда.

  1. Прохождение курса: 
    Ожидаемый результат: Ответы корректно проверяются. Появляется корректное сообщение ошибки в случае ввода некорректных данных (например, NULL или "abcd" вместо числового ответа).

  2. Проверка генерации задач:

    Фактический результат совпадает с ожидаемым.

  3. Проверка генерации задач по картинке:
    Ожидаемый результат: Картинка загружается. Корректно считывается информация о картинке. Задачи генерируются, могут генерироваться по типам. Ответы корректно проверяются. Появляется корректное сообщение ошибки в случае ввода некорректных данных (например, NULL или "abcd" вместо числового ответа).
    Фактический результат совпадает с ожидаемым. 
  
  4. Проверка визуализации:
    Ожидаемый результат: Корректно отображаются цвета, пиксели и т.д. Можно менять параметры картинки. Отображаются максимум 16*16 пикселей.
    Фактический результат совпадает с ожидаемым.
  
  5. Проверка Статистики: 
    Ожидаемый результат: корректно отображает статистику за всё время и за последние 10 задач.
    Фактический результат совпадает с ожидаемым.
